Montando a teia…

{{ .Title }}

Arraste para girar, role para aproximar e clique num ponto para abrir o dossiê. Passe o mouse sobre um ponto para ver o nome.

Como usar a Teia

  1. Cada ponto é um caso, uma pessoa, uma empresa, um órgão, um partido ou um lugar. As cores estão na legenda.
  2. Cada linha é uma ligação: quem foi condenado, cassado, delatou, foi citado ou teve o processo anulado em cada caso.
  3. Toque ou clique num ponto para abrir o dossiê, com o resumo e as ligações. No dossiê, toque num nome para ir até ele.
  4. Arraste para girar e use a roda do mouse, ou dois dedos, para aproximar.
  5. Em Filtros e busca, procure um nome, escolha quais tipos aparecem e use Caminho para ver como duas pessoas ou casos se conectam.
  6. A linha do tempo, embaixo, mostra só os casos que começaram até o ano escolhido.

Estar na Teia não significa ter sido condenado. O tipo de cada ligação diz qual foi o papel da pessoa no caso.
